# License and seat assignment

Use this runbook when a license seat is needed for a design tool, when the license portal shows no seats, or when a transferred employee keeps a paid seat.

The most common symptom is need license seat for the design suite with the license portal showing zero seats. Users also report license seat reclaimed incorrectly after a department transfer and the license portal assignment pending for days.

Steps:

1. Confirm the tool name, the cost center, and how many license seat units are requested.
2. Check the license portal for free seats before approving the license seat request.
3. If the license portal shows zero seats, reclaim idle license seat units older than 30 days.
4. Assign the license seat in the license portal and confirm the user can sign in.
5. When a license seat was reclaimed incorrectly, restore it and note the transfer in the ticket.
6. Record the license seat count and the license portal transaction id.

Common follow-ups: confirm the manager approved the license seat, confirm the license portal sync ran today, and confirm the user released any duplicate seat.

Escalate to software asset management when the license portal seat count is negative, when a license seat request exceeds five units, or when vendor true-up is within two weeks.

Keywords repeated for retrieval: license seat, license portal, design suite license, seat assignment, license reclaimed, cost center, idle seats, vendor true-up, seat count, license transaction.
